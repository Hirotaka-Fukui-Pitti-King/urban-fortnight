# Stage 3: Statistical Equilibrium and Entropy

**Status:** Planned. **Dependencies:** Stage 0, Stage 1, Stage 2.

## Central research question

When does the wealth-belief economy admit a justified stationary or maximum-entropy characterization?

## Economic mechanisms

- Stationary master/Boltzmann equations
- Entropy under derived constraints
- Non-equilibrium probability fluxes and metastability
- Order parameters and critical thresholds

## Economic closure and model caveats

- Do not assume an entropy maximizer is an economic equilibrium.
- State conservation laws, invariant measures, ergodicity and detailed balance where used.
- Allow non-equilibrium stationary states when detailed balance fails.

## Nested comparators

- Microscopic stationary simulation
- Derived distributional dynamics
- Constrained entropy approximation

## Acceptance tests

- Distribution normalization and moment constraints
- Invariance under the transition kernel
- Entropy approximation versus finite agents
- Explicit failure examples if assumptions break

## Deliverables

- Conditional analytical propositions
- Validated stationary density and phase diagram

**Progression gate:** The numerical equilibrium, accounting identities, convergence checks and nested comparator must be verified before moving to the next stage. Record the code revision, seeds and tolerances in `results/`.

**Literature starting points (verify during implementation):** Jaynes (1957); Statistical equilibrium economics.
